## Week 1 Activity Report

**Week:** 1 — Java Fundamentals  
**Scheduled Period:** 29 September – 5 October 2026  
**Report Prepared On:** 11 October 2026

### 1. Objective

The objective of Week 1 was to understand the fundamentals of Java programming, set up the development environment, and implement basic console-based programs.

### 2. Tasks Completed

**Task 1: Java Installation and Setup**
- Set up the Java Development Kit (JDK).
- Configured the development environment using Visual Studio Code.
- Verified Java and Java compiler availability through the terminal.
- Created and executed a basic Hello World program.

**Task 2: Variables, Data Types and Operators**
- Practised Java variables and basic data types, including `int`, `double`, `char` and `boolean`.
- Implemented arithmetic and comparison operators.
- Explored integer division, decimal division, remainder and increment operators.

**Task 3: Control Statements**
- Implemented `if-else` statements for decision-making.
- Practised `switch` statements.
- Used `for` and `while` loops for repetition.
- Understood the importance of `break` in switch statements.

**Task 4: Student Grade System**
- Developed a console-based Java program to calculate a student's total marks, percentage and grade.
- Accepted student information and subject marks.
- Implemented basic marks validation.
- Displayed the calculated result in a structured format.
- Practised arithmetic operations, conditional statements and formatted output.

### 3. Technologies and Tools Used

- Java
- JDK 24
- Visual Studio Code
- Command-line terminal

### 4. Learning Outcomes

By the end of Week 1, I practised:

- Writing, compiling and executing Java programs.

- Applying conditional statements and loops.

### 5. Conclusion

Week 1 provided practical experience with Java fundamentals and console-based programming. The tasks helped build a foundation for the upcoming topics, including object-oriented programming, exception handling, file handling and database connectivity.
